# Lab 45: Inheritance and Method Overriding

This lab demonstrates method overriding, polymorphism, `super()`, method resolution order (MRO), and multi-level inheritance in Python.

## Run

```bash
python3 complete_method_overriding_lab.py
```

No third-party packages are required.

## Concepts covered

- Base class methods and overrides in derived classes.
- Polymorphism: the same method call produces different outputs for different object types.
- Method Resolution Order through `Class.__mro__`.
- Vehicle, Car, and Motorcycle classes overriding engine, acceleration, and info methods.
- `super()` to reuse parent constructors and parent method behavior.
- ElectricCar, LuxuryCar, and SportsCar inheritance examples.
- Sport mode behavior and an override-chain demonstration.
