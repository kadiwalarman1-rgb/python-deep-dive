# Lab 24: String Formatting and Advanced Manipulation

## What You Will Learn

- Format text with positional, indexed, and named format() arguments.
- Use f-strings for values, expressions, numeric formats, and date/time output.
- Apply advanced slicing to strings and extract useful substrings.
- Count character frequencies using Counter.
- Use regular expressions to find email/phone patterns and normalize text.
- Work with multiline strings and escape sequences.
