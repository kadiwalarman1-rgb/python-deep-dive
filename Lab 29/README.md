# Lab 29: Final Project - Combining Data Structures and File I/O

## What You Will Learn

- Read and validate employee records from CSV with csv.DictReader().
- Organize employees and department memberships with dictionaries and lists.
- Add, update, remove, and search employee records.
- Calculate salary statistics and department averages.
- Export data and reports to JSON, CSV, and text formats.
- Handle file and record errors, use a safe file context manager, and log invalid rows.
- Process a larger CSV file in batches rather than storing all raw rows at once.

## Run

python3 lab_29.py

Generated sample input and export files are stored in lab29_output/.
