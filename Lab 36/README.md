# Lab 36: Introduction to Classes and Objects

## What You Will Learn

- Define classes and create objects using __init__ and self.
- Store and update instance attributes.
- Create multiple independent objects from one class.
- Add methods to display and modify object state.
- Use classes for people, counters, students, and vehicles.
- Handle invalid values and test object behavior.

## Files

- person_class.py — first Person class example.
- multiple_persons.py — multiple people and independent object state.
- enhanced_person.py — profile attributes, friends, and age groups.
- self_demo.py — a Counter class showing how self works.
- student_system.py — student courses, grades, GPA, and academic status.
- object_experiments.py — vehicle state changes and dynamic object creation.
- advanced_test.py — automated tests for the examples.

## Run

Run commands from this folder:

    python3 person_class.py
    python3 multiple_persons.py
    python3 enhanced_person.py
    python3 self_demo.py
    python3 student_system.py
    python3 object_experiments.py
    python3 -m unittest advanced_test.py -v

No third-party packages are required.

## Notes

The examples are based on the provided Lab 36 material. The programs have been completed as runnable scripts, with basic input validation added where needed. The Student GPA calculation uses the simple grade-to-points mapping described in the lab; it is an educational example, not a universal grading standard.
