# Lab 43: Magic Methods

This lab demonstrates Python's special (dunder) methods and operator overloading.

## Run

```bash
python3 lab_43.py
```

## Concepts covered

- `__str__` and `__repr__`: readable object output and useful debugging representations.
- `__add__`: custom addition for vectors, books, playlists, and bank accounts.
- `__eq__`, `__lt__`, `__le__`, `__gt__`, and `__ge__`: object comparisons.
- `__len__`: let a playlist work with `len()`.
- `__bool__`: use a bank account in a Boolean context.
