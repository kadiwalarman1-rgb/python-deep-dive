# Lab 26: File Input and Output - Working with CSV Files

## What You Will Learn

- Read CSV rows with csv.reader() and records with csv.DictReader().
- Convert CSV text fields to numbers and analyze scores.
- Filter records, calculate averages, and count category values.
- Write CSV data with csv.writer() and csv.DictWriter().
- Handle missing files, malformed rows, and CSV/file errors.

## Run

python3 lab_26.py

The script creates sample CSVs and output reports in lab26_output/.
