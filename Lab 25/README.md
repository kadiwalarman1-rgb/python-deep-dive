# Lab 25: Files and Input/Output - Basic File Operations

## What You Will Learn

- Read text files in text and binary modes.
- Write and append text without losing existing contents.
- Use with open() to close files automatically.
- Process files one line at a time and count words.
- Handle missing files and other file-system errors.

python3 lab_25.py
