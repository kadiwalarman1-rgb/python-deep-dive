# Lab 31: Importing Modules and Using Standard Libraries

## What You Will Learn

This lab introduces Python's built-in standard library modules and how to use them in practical scripts.

- Use the `math` module for square roots, trigonometric functions, and constants such as `pi` and `e`.
- Use the `random` module to generate random floating-point numbers and integers.
- Create a simple dice-rolling function with `random.randint()`.
- Use the `datetime` module to get the current date and time, format dates, and calculate future dates with `timedelta`.
- Combine `random` and `datetime` to generate random dates within a given year.
- Import modules with aliases using the `as` keyword.

## Files

- `math_demo.py` — mathematical operations and constants.
- `random_demo.py` — random numbers and dice rolls.
- `datetime_demo.py` — current date/time, formatting, and date arithmetic.
- `random_date.py` — random date generation.
- `alias_demo.py` — module aliases.

## Run

Use Python 3 to run any example from this directory. For example:

```bash
python3 math_demo.py
python3 random_demo.py
python3 datetime_demo.py
python3 random_date.py
python3 alias_demo.py
```
