# Lab 27: File Manipulation - Reading and Writing JSON Files

## What You Will Learn

- Read and parse JSON files with json.load().
- Serialize Python dictionaries and lists with json.dump().
- Work with nested lists and dictionaries to extract specific values.
- Add, update, and delete records and fields in JSON data.
- Handle malformed JSON and file errors.
- Validate record structure and serialize dates using a custom JSON encoder.

## Run

python3 lab_27.py

Sample inputs and outputs are created in lab27_output/.
