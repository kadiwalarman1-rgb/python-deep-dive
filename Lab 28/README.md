# Lab 28: Advanced File I/O Operations - Context Managers

## What You Will Learn

- Use with open() to manage file resources safely.
- Compare explicit file closing with context managers.
- Read a file, add line numbers and word counts, and write processed output.
- Copy large files in binary chunks instead of loading the whole file into memory.
- Count file size and lines with chunk-based processing.
- Handle missing files, permissions, and other file-system errors.
- Write timestamped log entries.

## Run

python3 lab_28.py

Sample and output files are created in lab28_output/.
